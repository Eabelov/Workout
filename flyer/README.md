# Листовка High Heels

Готовые файлы:

- `flyer.png` — версия 1748 × 2480 px для публикации;
- `flyer.pdf` — печатная версия A5 (148 × 210 мм);
- `flyer.svg` — редактируемый исходник с внедрёнными изображениями и шрифтами.

QR-код ведёт на `https://vk.ru/club237181940`. После финального экспорта код
проверен декодированием из PNG.

Чтобы пересобрать все форматы:

```bash
python3 flyer/generate_flyer.py
```

Для экспорта PNG и PDF скрипту нужен Chromium или Google Chrome. SVG создаётся
без дополнительных зависимостей.
